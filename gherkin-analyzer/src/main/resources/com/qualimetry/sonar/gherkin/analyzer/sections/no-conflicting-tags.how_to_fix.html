Compliant Solution

Remove the contradictory tag:

Feature: Feature development

  @wip
  Scenario: Work in progress feature
    Given a new feature is being developed
    When the feature is partially implemented
    Then the tests should indicate incomplete work

Configuration

The conflictPairs parameter defines which tag pairs are considered conflicting. Each pair uses + as separator, and pairs are comma-separated. Tag names are specified without the @ prefix.

ParameterTypeDefault
conflictPairsString(empty)

Example: wip+release-ready,manual+automated,slow+fast

When the default empty value is used, the rule is effectively inactive and will not report any issues.
