Reduce the Background to essential shared setup:

Feature: Complex setup

  Background:
    Given a registered user with full profile
    And the user is logged in

  Scenario: View settings
    When the user navigates to settings
    Then the settings page is displayed

Configuration

The maxSteps parameter controls the maximum number of steps allowed per Background. The default value is 5. Teams with complex shared setup can raise the limit.
