Given steps should match the configured regular-expression pattern. This rule lets teams enforce naming conventions on precondition steps — for example, requiring them to start with a noun phrase such as “the” or “a”. And/But steps continuing a Given are checked as well. If the configured pattern is not a valid regular expression, a file-level issue is raised instead of failing the analysis.

Noncompliant Code Example

With the pattern ^the .*:

Feature: Account management

  Scenario: Deactivate an account
    Given user has an active account                   <!-- Noncompliant -->
    When the account is deactivated
    Then the account status is inactive
